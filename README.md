# RS Coach – web app

The browser / iPhone version of the RS Coach app. This repo holds only the app's files; each athlete's data
lives in their own private repo, and their keys are entered on their own phone.

**Install on iPhone:** open the GitHub Pages link in Safari → Share → **Add to Home Screen**.
Then open it and, in Settings, enter your data repo (owner/name), your GitHub token and your Anthropic key.

Updated automatically from the main app repo.
